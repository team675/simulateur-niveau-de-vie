# Niveau de vie France–Suisse

Simulateur de rendez-vous du Suisse Project : salaire et charges en France contre salaire frontalier suisse, imposition automatique (barème IR français, barèmes source Genève 2026), coût de l'accompagnement, projection à dix ans.

Un seul fichier : `simulateur-niveau-de-vie.html`, à ouvrir dans un navigateur. Paramètres chiffrés dans l'objet `P` en tête du script (à mettre à jour chaque janvier).
